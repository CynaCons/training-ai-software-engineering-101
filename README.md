# Agentic AI Software Engineering — Training

Interactive slide-based training draft. Built with React + Vite for visual iteration.

## Quick start

```bash
npm install
npm run dev
```

Open the URL shown in the terminal (usually `http://localhost:5173`).

## Navigation

- **Arrow keys** or **Prev/Next** — move between slides
- **C** or the **Canvas** toggle — see all slides on a pannable, zoomable canvas
- Click a slide in canvas view to jump back to presentation mode

## Structure

```
src/
  components/     # Slide card, canvas, interactive diagrams
  slides/         # Slide content (edit here to change copy)
  styles/         # Design tokens & global styles
```

## Visual theme (draft)

- **Blueprint Workshop** — dark slate surfaces, blueprint grid, teal accent, amber code highlights
- Fonts: Syne (display), Outfit (body), IBM Plex Mono (code)

This is a starting point for iterating on palette, typography, motion, and slide layouts.
